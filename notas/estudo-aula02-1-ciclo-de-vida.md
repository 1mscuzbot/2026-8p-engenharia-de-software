## Ideia central

**Ciclo de vida** = processos/tarefas da concepção até a descontinuidade. Serve para mapear fases, entregas e responsabilidades.

**Benefícios:** planejar melhor, corrigir cedo (menor custo), localizar erros, facilitar manutenção.

### Etapas básicas

| Etapa | Conteúdo |
|-------|----------|
| **Definição** | situação atual → problema → solução; modelagem; escolha do modelo |
| **Desenvolvimento** | projeto, protótipo, código, testes, integração |
| **Operação** | treinamento, correção, continuidade |

---

## Modelos (estrutura das fases)

| Modelo | Em uma frase |
|--------|----------------|
| **Cascata** | fases sequenciais; fácil gestão; mudança tardia é cara |
| **Modelo V** | cascata em V com verificação/validação emparelhada a cada fase |
| **Incremental / iterativo** | entregas parciais; bom com requisitos incompletos |
| **Evolutivo** | mudanças contínuas; alta interação; escopo difícil de fechar |
| **Espiral (Boehm)** | voltas com análise de risco; bom para produtos internos |
| **Prototipação** | protótipo → feedback → refino; risco: cliente achar que o protótipo é o produto |

**Modelo × método:** modelo = estrutura abstrata das fases; método = prescritivo (técnicas, papéis) — ex.: Scrum, XP, RUP.

### Métodos (amostra)

- Tradicionais: **RUP**, **Cleanroom**
- Ágeis: **Scrum**, **XP**, **Kanban**
- Modernos/híbridos: **DevOps**, **Lean**, **FDD**
